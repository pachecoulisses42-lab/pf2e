Brigandine DS

Sistema visual do motor tático Brigandine, com dois temas. Pergaminho (padrão): interface de RPG com papel envelhecido, contorno marrom grosso, plaquinhas de madeira, botões verde/vermelho e dicas escuras. Moderno: grafite frio com acento por modo. Nos dois, as cores de jogo são reservadas: cada uma significa uma coisa só.

Alterne o modo no canto superior para ver o acento mudar. Todos os valores vêm de src/styles/tokens.css.

O que existia no v4

Extraído do arquivo original e mapeado para o novo sistema. O v4 usava valores crus repetidos em ~800 linhas de CSS; o v5 concentra tudo em tokens.

Tokens de peça — Chibi (padrão)

Personagens de corpo inteiro com cabeça grande, contorno marrom grosso, cores chapadas com um tom de sombra e expressões fortes. Cada um fica sobre uma base oval na cor da classe (anel claro para heróis, vermelho para vilões). Desenhados com o kit de 00d-chibi-kit.js. Você também pode importar suas próprias imagens (uma a uma ou várias de uma vez como modelos).

Estilo alternativo: vista de cima

Personagens vistos do alto, virados para o sul, com luz de cima-esquerda, volumes pintados, grão de tinta e sombra projetada macia, sem moldura. Desenhados com o kit de 00i-topdown-kit.js. Selecionável em Peças → Estilo dos tokens.

Princípios

Mostre uma coisa por vez. Painéis usam acordeões, abas e gavetas: o tabuleiro fica sempre em evidência. Configurações raras (ajuste rápido de grade, legenda, modelos) ficam recolhidas.

Cor tem significado. Vermelho é alcance e ataque, verde é movimento, roxo é magia, âmbar é item, azul-gelo é defesa. Nunca decoração.

Resumo primeiro, detalhe sob demanda. Listas mostram nome, bônus e dano em uma linha; o editor completo abre só ao tocar no lápis. O registro mostra a última rolagem e expande em uma gaveta.
